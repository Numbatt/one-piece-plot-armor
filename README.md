# One Piece Plot Armor

A browser extension that hides One Piece spoilers across social media, tuned to
exactly how far you are in the story. You tell it your episode; it blurs the
stuff you haven't earned yet — manga leaks, future forms, deaths, twists —
across Reddit, Twitter/X, Instagram, and more.

One Piece only, on purpose: the most-watched anime on Earth, 1000+ episodes, a
fanbase that will riot over a leaked panel. Narrowing to one bounded, obsessively
documented world is what lets us be *precise* instead of paranoid.

See [PLAN.md](./PLAN.md) for the architecture and build plan.

> Status: started fresh. Reuses lessons (not code history) from an earlier
> general-purpose prototype.
