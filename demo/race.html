Cost is computed from measured token usage at published list prices. Cerebras sells latency, not price per token — expect it to win the clock and lose the dollar column.

Fairness controls in effect:
  • byte-identical system prompt, user prompt & JSON schema across lanes
  • identical batch size and concurrency limit
  • one discarded warm-up call per lane before timing starts
  • lanes run concurrently, so network drift hits both equally
  • timings measured server-side, at the call site
